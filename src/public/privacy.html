Avy Privacy Policy

Last updated: November 13, 2026

Avy is a Discord bot. This page explains what data Avy uses, why, and what happens to it. By using Avy, you agree to this policy.

What Avy uses and why

  • Slash commands. When you run a command, Avy uses what you type to do it. The prompt you give /draw is sent to a third-party AI image service hosted on Hugging Face, and Avy posts the image it returns. The link you give /tomp4 is used to download that video so Avy can upload it as an MP4.
  • Rowa chat bridge. In one designated channel in the Rowa Discord server, Avy sends each message's author username and the first 128 characters of its text to the Rowa Roblox game through Roblox's Open Cloud Messaging Service, so players in the game can see it. Messages in any other channel are not used for this.
  • Text commands. Messages that start with Avy's command prefix are read only so Avy can run that command.
  • Server information. When Avy is added to a server, the developers are notified of that server's name and ID.
  • Developer status. Avy records whether its own developer is online, once an hour, for a personal status history. No other user's online status is recorded.
  • Error logs. If something goes wrong, Avy writes a short log for debugging. This log can include usernames, IDs, or command input involved in the error.

What Avy stores

  • Avy does not store your messages or command input in a database.
  • The developer's hourly online status is stored in Google Firebase.
  • Error logs are kept in memory and in the hosting provider's logs, and only the developers can see them.

What Avy never does

  • It does not sell or rent your data.
  • It does not use your messages to train AI or machine learning models.
  • It does not share your data with anyone except the services listed above, and only so a feature can work.

Your choices

  • If you don't want your messages sent to the Rowa game, don't post in the bridge channel.
  • You can stop Avy from seeing a server by removing it from that server.
  • To ask a question or have data about you removed, contact the developer on Discord: airzy.

Changes

If this policy changes, the date at the top of this page will change too.
